## Inner systems

### Motors — thrust, delay, ejection

A model rocket <GlossaryTerm id="motor">motor</GlossaryTerm> burns in three steps:

1. **Thrust** — hot gas out the nozzle lifts the rocket  
2. **Delay** — smoke only; coast toward <GlossaryTerm id="apogee">apogee</GlossaryTerm>  
3. **Ejection** — gas pulse opens the recovery bay  

Code reminder: letter = impulse class · middle number = average thrust (N) · last number = delay seconds (example **F42-6**).

**ARC:** class **F** motors only, from the approved list.

### Altimeter — how altitude is scored

The <GlossaryTerm id="altimeter">altimeter</GlossaryTerm> reads air pressure. **Only these four are allowed:** PerfectFlite Pnut, PerfectFlite FireFly, Jolly Logic Altimeter One, Jolly Logic Altimeter Two.

Put it in a hard case. Add **vent holes** so outside air reaches the sensor.

### Parachute, shock cord, Nomex

After ejection, the <GlossaryTerm id="parachute">parachute</GlossaryTerm> slows the rocket. **ARC requires cotton canopies.** Bigger chute → longer flight time. A spill hole can shorten time if you overshoot — risky, not free.

Place <GlossaryTerm id="nomex">Nomex</GlossaryTerm> (real fire fabric) **between** the ejection charge and the chute/shock cord. Pack it loose enough to open.

## Outer airframe

| Part | Job | Rule to remember |
| --- | --- | --- |
| <GlossaryTerm id="body-tube">Body tube</GlossaryTerm> | Structure + holds everything | Same diameter nose→tail · ≥ 47 mm · length ≥ 650 mm · non-metal |
| <GlossaryTerm id="nose-cone">Nose cone</GlossaryTerm> | Cuts drag; often holds shock cord | Non-metal · separates cleanly · pull-test on the bench |
| <GlossaryTerm id="fins">Fins</GlossaryTerm> | Keep CP behind CG | Non-metal · straight + strong · ~1.5–2 caliber margin |

## Simulate, then prove it

Use <GlossaryTerm id="openrocket">OpenRocket</GlossaryTerm> to predict altitude, time, stability, and descent **before** you cut. Then fly, compare the altimeter to the sim, and fix the model (often drag).

<Callout tone="caution" title="Sim ≠ score">
  Software narrows choices. Practice flights decide what is true on your rocket.
</Callout>

## Fault map

| Symptom | Check first |
| --- | --- |
| Wrong height / chute timing | Motor delay · ejection · packing |
| Nonsense altitude | Vents · altimeter case · battery |
| Burned chute / no deploy | Nomex placement · pack tightness |
| Cracked egg | Padding · descent rate · landing |
| Crooked flight / broken fin | Fins · CG/CP · nose fit |

Learn the photos. Use the map. That is how a team debugs instead of guessing.
